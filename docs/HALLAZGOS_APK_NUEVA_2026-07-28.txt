1. SOLUCIÓN AL PROBLEMA DE FOTOS DE PRODUCTOS (ya implementada en el CRM)
================================================================================
El sistema principal entrega FOTO_URL como ruta local de Windows del servidor:
  T:\productosImagenes\{codigo}.png

La app oficial arma la URL HTTP real así (ProductosCatalogoAdapter.java):
  1. Toma el texto de FOTO_URL desde "productosImagenes" en adelante
  2. Cambia \ por /
  3. Le antepone: https://agrofer.link/sistemas/vistas/img/productos/

URL final funcional:
  https://agrofer.link/sistemas/vistas/img/productos/productosImagenes/{codigo}.png

Verificado en vivo: HTTP 200, image/png, imagen real del producto.
Ya implementado en backend/src/routes/productos-catalogo.js (función resolveFotoUrl).
99.6% de los 4,262 productos tienen foto (4,246 con match).

4. OPORTUNIDAD PRINCIPAL: Seguimiento de pedidos al estilo e-commerce
================================================================================
Idea: cuando un cliente hace un pedido, informarle por WhatsApp cada vez que cambia
de etapa (creado → despachado → en reparto → entregado / con novedad), igual que
un e-commerce (Mercado Libre, Amazon, etc.) le avisa al comprador.

Fuente de datos: get_seguimiento_pedidos_vendedor_v2 (o el endpoint equivalente que
haya para consultar por cliente/pedido en vez de por vendedor — falta confirmar si existe
una variante "por cliente").

Piezas que harían falta (pendiente de diseñar, NO implementado todavía):
  - Job que consulte periódicamente el estado de pedidos activos y detecte cambios
    de etapa (comparando contra el último estado guardado).
  - Mapeo pedido → cliente → teléfono (ya tenemos teléfono de los 3,753 clientes
    sincronizados desde get_clientes).
  - Plantillas de mensaje por etapa (creado, despachado, en reparto, entregado, novedad).
  - Decidir canal de envío: línea de WhatsApp normal (whatsapp-web.js) o Meta Cloud API
    con message templates (más robusto para mensajes iniciados por el negocio, ya que
    fuera de la ventana de 24h de conversación WhatsApp exige plantillas aprobadas).

Este archivo es solo un registro de referencia — no se ha construido nada de la sección 4 todavía.
